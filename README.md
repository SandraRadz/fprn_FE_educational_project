# ФПрН — фронтенд

Готовий React-фронтенд для практики з Django REST. Його не треба змінювати: достатньо запустити і реалізувати бекенд за специфікацією з `README_BE.md` бекенду.

## Запуск

Потрібен Node.js 18 або новіший.

```bash
npm install
npm run dev
```

Сайт відкриється на http://localhost:5173.

Фронтенд звертається до бекенду на `http://localhost:8000`. Якщо бекенд працює на іншій адресі, скопіюйте `.env.example` у `.env`, змініть `VITE_API_URL` і перезапустіть `npm run dev`.

## Що є на сторінці

- **Головна, Кафедри, Викладачі, Курси** — навігація вгорі.
- На кожній сторінці ресурсу є форма (**Створити** / **Зберегти зміни**), кнопка **Отримати список** і кнопки **Редагувати** та **Видалити** в рядках таблиці.
- Помилки валідації від сервера (`400`) показуються під відповідними полями форми.
- Панель **«Відповідь сервера»** у правому нижньому куті показує метод, адресу, статус, тіло й хедери останньої відповіді, які доступні JavaScript.
